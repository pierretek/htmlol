Minecraft Server Skripts

Very useful skript snippets for any minecraft server!

Announce Command ➤ 

command /announce [<text>]:
    permission: op
    trigger:
        set {_text} to colored arg-1
        send title "&6&lANNOUNCEMENT!" with subtitle {_text} for 5 seconds
        send "&6&lANNOUNCEMENT! &f%{_text}%"
Custom Join/Leave Messages ➤ 

options:
    serverPrefix: [SERVER_NAME_HERE]

on join:
    
    if player has played before:
        set join message to "&a{@serverPrefix} &f%player% &ajoined the game!"
    else:
        set join message to "&b{@serverPrefix} &f%player% &ejoined for the first time! &7[#&e%size of all offline players%&7]"

on quit:
    set quit message to "&c{@serverPrefix} &f%player% &cleft the game!"
Anti-Naked Killing ➤ 

options:
	combat-duration: 5 seconds
	
on damage of player:
	attacker is a player
	attacker is not op
			
	if armor of attacker is air:
		cancel event
		send "&cYou need to wear armor to PvP!" to attacker
		stop	
		
	if armor of victim is air:
		cancel event
		send "&cYou cannot attack naked players!" to attacker
		stop
		
	# Put both players in combat
	set {combat::%attacker's uuid%} to now
	set {combat::%victim's uuid%} to now
	
on inventory click:
	player is not op
	{combat::%player's uuid%} is set
	event-slot is 36 or 37 or 38 or 39
	difference between {combat::%player's uuid%} and now < {@combat-duration}
	
	cancel event
	send "&cYou cannot change your armor during a fight!" to player
	
on quit:
	delete {combat::%player's uuid%}

Spawn Command ➤ 

options:
    teleporting-time: 5 seconds

command /spawn:
    trigger:
        send "&6ᴛᴇʟᴇᴘᴏʀᴛɪɴɢ ᴛᴏ ꜱᴘᴀᴡɴ ɪɴ %{@teleporting-time}% (ᴅᴏɴᴛ ᴍᴏᴠᴇ)"
        set {teleporting.%player%} to true
        wait teleporting-time
        if {teleporting.%player%} is true:
            execute console command "/minecraft:tp %player% -136 109 298"
            send "&aᴛᴇʟᴇᴘᴏʀᴛᴇᴅ ᴛᴏ ꜱᴘᴀᴡɴ!"
        delete {teleporting.%player%}

on player move:
    if {teleporting.%player%} is true:
        send "&c&oʏᴏᴜ ᴍᴏᴠᴇᴅ, ᴛᴇʟᴇᴘᴏʀᴛ ᴄᴀɴᴄᴇʟᴇᴅ"
        delete {teleporting.%player%}
Set Spawn Location Command ➤ 

command /setspawnloc:
    permission: op
    permission message: &cYou do not have permission to use this command!
    trigger:
        set {respawn.join.location} to location of player
        send "&aRespawn & Join location set to your current position!"

on join:
    if {respawn.join.location} is set:
        teleport player to {respawn.join.location}

on respawn:
    if {respawn.join.location} is set:
        teleport player to {respawn.join.location}
AFK Pool Tokens ➤ 

options:
	afkTokenName: TOKEN_NAME_HERE
	afkTokenCooldown: 60 seconds

every {@afkTokenCooldown}:
    loop all players:
        if "%region at loop-player%" contains "afk":
            send "&7GG! You Got a Reward for Being AFK!" to loop-player
            play sound "entity.experience_orb.pickup" with volume 1 to loop-player
            give sunflower named "{@afkTokenName}" to loop-player
